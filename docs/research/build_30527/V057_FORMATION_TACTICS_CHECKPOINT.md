# v0.5.7 Formation + Tactics Checkpoint

## Decision

Formation/Tactics static research is sufficiently mature to freeze a **v1 companion baseline** while keeping known private/server formulas unresolved.

### Default long-term Target Formation — COMPANION LOGIC

`GK / DL DC DC DR / DMC MC / AML AMC AMR / ST`

Equivalent family: 4-2-3-1 with one DMC pivot and one MC pivot.

This is not claimed as a universal Nordeus best formation. It is the current tool's long-term recruitment target because it:
- satisfies every current native hard rule;
- triggers none of the current irregular warnings;
- is symmetric;
- passes the transparent one-slot advisory-robustness filter;
- covers 18/19 active Playstyles;
- keeps centre + both flanks + a deep midfield screen + four advanced attacking roles available;
- remains compatible with possession, direct-counter, flank, centre and pressing plans.
