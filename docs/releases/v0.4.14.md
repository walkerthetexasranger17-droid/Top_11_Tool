# Top Eleven Tool v0.4.14

## Scanner accuracy patch

Real-device testing of v0.4.13 showed a strong level-classification bias: Intermediate badges were repeatedly returned as Standard, with one Intermediate Inside Forward returned as Master. The exact reference PNG labels were rechecked and were correct, so this release changes the recognition path rather than the assets.

- Keeps all 260 approved playstyle-state PNGs unchanged.
- Keeps all 19 coloured Special Ability references unchanged; gold/boosted Special Ability references remain disabled.
- Automatically isolates the small playstyle badge from the player-name strip before visual comparison.
- Supplies both RAW pixel-preserving and SMOOTH enlarged badge evidence.
- Replaces the 13-state level collage with five individual exact references for the selected playstyle: Standard, Intermediate, Advanced, Master and Locked.
- Requires Gemini to count the three level-ring segments explicitly: `000 / 100 / 110 / 111` (right / bottom / left) -> Standard / Intermediate / Advanced / Master.
- The app resolves the final unlocked level from the explicit right/bottom/left segment booleans first, with `darkSegmentCount` retained as a consistency check. A contradictory verbal label cannot win.
- Ready, Boosted and Wrong Position are moved to a separate overlay-only pass.
- Adds an exact Ball Playing DC vs No-Nonsense DC confirmation pass for that known visual lookalike.
- No benchmark player names or expected answers are included in production scanner prompts.
