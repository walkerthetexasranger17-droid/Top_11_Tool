# v0.5.12 — Own-Squad Decision Runtime

**Date:** 15 September 2026  
**Status:** implementation checkpoint / fail-safe recovery build

v0.5.12 is the first build where the v2 Formation + Tactics + Mentor decision contract is wired into the runtime rather than remaining a staged data model.

## Permanent architecture decision

The optimiser never asks for, stores, infers, or scores another team's formation, strength, tactics, passing style, attack profile or any relative-strength estimate. It also does not require live match state for the pre-match recommendation path. The decision input is the manager's own squad, candidate XI/roles, player skills, active Playstyles, Special Abilities, saved Mentor unlock/level state, Approach and Drain Limit.

An effect whose real activation needs information outside that input model receives zero pre-match ranking credit. The app does not invent a proxy simply to make the effect scoreable.

## Decision contract

`data/build_30527/index/decision_logic_v2.json` is now v0.5.12 own-squad authority. It contains:

- 12 formation candidate families;
- 11 own-structure formation rules;
- 60 own-XI / internal-coherence / Playstyle-SA tactic rules;
- exact 11-dimension build-30527 tactic option/drain domains;
- own-XI feature definitions and player-cluster calculations;
- level-gated Mentor scoring;
- role and role+Playstyle training hierarchies;
- squad coverage/recruitment blueprint.

`strategy_strings_v2.json` contains 136 active explanation strings. Removed matchup strings are intentionally not retained as dead runtime content.

## Formation scoring

100-point transparent companion score:

- Lineup quality: 35
- Playstyle-role fit: 10
- Weak link: 15
- Core own-team structure: 30
- Natural-role flexibility: 10

The runtime consumes all 12 candidates from the JSON contract directly. If none can be fielded, automatic selection falls back to the recovered 2,843 hard-legal natural-role shapes and scores them with the same own-squad model. No formation matchup component or strength modifier remains.

## Tactics scoring

100-point transparent companion score:

- Native XI option fit: 32
- Own-squad structure: 26
- Internal tactic coherence: 18
- Playstyle / Special Ability fit: 14
- Condition-drain efficiency: 10

The recovered build-30527 condition-drain calculation and all 97,200 tactic combinations remain unchanged. Drain efficiency now maps the exact theoretical minimum raw drain **30** to the full 10 points and the selected Low/Medium/High ceiling (40/65/100) to zero. Marking matchup efficacy is not guessed. The neutral fallback can still prefer the lower-drain stable option, and strong own marker capacity may establish feasibility without claiming unseen matchup superiority.

## Mentor scoring

Mentor unlock gates remain Level 1 / 5 / 10 for Tactical / Attribute / Signature families.

- Tactical: up to 40 from a known own-plan condition or own-plan feature.
- Attribute: up to 25 from actual assigned-role white-skill relevance using the role/Playstyle hierarchy and tactic-context modifiers. Training-only Special Ability context does not leak into this score.
- Signature: up to 30 only when its activation can be proven from the pre-match own-plan context.
- Tradeoffs are subtracted only when their family/context is active.
- Plan adjustment: `10 × clamp(raw / 95, 0, 1)`.

External/live-only examples remain documented but score zero in this pre-match runtime. This notably prevents speculative credit for Makélélé's context-specific Tactical family.

## Joint Formation + Tactics + Mentor selection

Formation and Tactics form the core plan at 50% / 50%. Only plans within 10 points of the best core plan are eligible for the 0..10 Mentor adjustment. A Mentor therefore refines a strong plan; it cannot rescue a structurally weak Formation/Tactics combination. With no unlocked Mentor the adjustment is zero and the plan is still valid.
