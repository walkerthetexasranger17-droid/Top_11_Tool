# v0.6.33 — Training Results Persistence Hotfix

Focused fix for Individual Training results disappearing shortly after Build Session.

The generated result was correct, but persisting the session to cloud could be echoed back as a false-positive data change, causing a full Training repaint. The cloud reconciliation layer now suppresses byte-identical server acknowledgements, and no-op cloud sync events no longer repaint the current page.

No training scoring, football logic, scanner calibration, Home/Squad design or Training visual design changed.
