# v0.5.15 — Whole-System Calibration Release

**Release freeze:** 2026-09-16

v0.5.15 freezes the calibrated own-squad decision engine built on the v0.5.14 pre-calibration baseline.

## All-in-one planner

The complete release path is:

`eligible squad → Formation/XI → Tactics → Set Pieces/Captain → Mentor → final Team Plan → Training context`

A direct `TeamPlan.buildOptimalPlan()` release regression protects the combined engine in addition to subsystem tests.

## Formation / XI calibration

- Formation score is 40 lineup quality + 10 Playstyle-role fit + 20 weak-link protection + 30 structural quality.
- Candidate-relative quality scaling was replaced by fixed absolute gap scaling to remove cliff behaviour.
- Structural scoring uses the proven global raw range -13..+30.
- Playstyle-role fit is starter-based rather than active-Playstyle-normalised.
- Exact XI selection retains Pareto-relevant assignments so weak-link and Playstyle fit are not discarded by a tiny mean-quality edge.
- Natural-role fallback and player-pool isolation are regression-locked.

## Tactics / semantic calibration

- Current Playstyle/active-SA affinity data is consumed at runtime.
- A Playstyle contributes only when active and eligible for the player's current assigned role.
- Secondary counter-runner and dribble-reliance/Mentor features use the same gate.
- Identity-only overlaps already represented by explicit tactic rules are de-duplicated.
- Exact hard-legal Playstyle/SA semantic range is **74 raw → 14 points**.
- Weak unused reserves and non-selected players cannot leak into XI-dependent tactic features.

## Special Ability identity correction

- **Shadow Striker** is the sole player-facing Special Ability identity.
- `LongShots` is retained only as internal/historical import/provenance compatibility and is never displayed as a separate “Long Shots” ability.

## Condition drain boundary

Current live Low/Medium/High option-intensity observations and pure-class transition facts remain preserved. The mixed Medium↔High exchange rate is not proven, so v0.5.15 deliberately does **not** invent a numeric live drain total. Safe categorical/partial ordering remains in use.

## Mentors / Set Pieces / Training

- Mentor effects remain unlock-gated and contained to viable core plans; unknown server magnitudes are not fabricated.
- Set Piece readiness remains a near-tie-only influence; Captain remains gameplay-neutral.
- Training keeps the specialist target-shape model and verified 1/2/3/4/5 base-XP intensity ladder.

## Release identity / cache

- visible/runtime version: `0.5.15`;
- Strategy model: `companion-strategy-v2-own-squad-runtime-v0515`;
- Team Plan schema: v6;
- service-worker cache: `te-v0-5-15`;
- runtime asset cache-buster: `r=0515`.

The canonical decision JSON and browser `strategy-data.js` bundle are synchronized at release freeze.

## Unresolved, intentionally not guessed

- mixed Medium/High live tactic-drain arithmetic;
- exact Mentor per-level server magnitudes;
- exact current Set Piece specialist magnitude;
- Training age-rate server values.

These are evidence boundaries, not placeholders to fill by estimation.
