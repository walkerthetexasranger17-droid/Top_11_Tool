# v0.5.11 — Decision Logic Bible / Data Contract

This build deliberately slows the decision-engine work down and makes the reasoning data explicit before full runtime wiring.

## Added

- `decision_logic_v2.json` as the authoritative Formation/Tactics/Mentor/Training companion-logic contract.
- `strategy_strings_v2.json` with 158 human-readable explanation strings.
- formal feature definitions so terms such as `aerialOutlet`, `counterOutlet`, `pressCapacity` and `lineSpeed` cannot be reinterpreted by a later session.
- 12 base role training hierarchies and all 28 currently offered role+Playstyle combinations.
- 12 formation families, 20 high-impact formation rules and dynamic legal fallback policy.
- 64 tactic rules across all 11 tactic dimensions, including neutral/default and contradiction logic.
- strict manual Mentor state with L1/L5/L10 Tactical/Attribute/Signature gates and explicit trade-offs.
- three-layer squad coverage: core XI, formation flexibility and availability depth, using unique-player assignment.
- expanded tactic-context Training modifiers with caps so tactics tune rather than redefine player identity.
- strengthened data-contract regression tests.

## Active foundations

- Individual Training now uses role-specific Playstyle profiles rather than the old `max(role, Playstyle)` shortcut.
- Squad coverage uses unique-player assignment so one versatile player cannot satisfy multiple simultaneous slots.

## Deliberately staged

The full generic Formation/Tactics/Mentor evaluator does **not** yet consume every v2 rule. The older hand-written scorer remains compatibility scaffolding. This build must not be described as having the complete v2 match-plan score active until the next wiring pass is finished and regression-tested.

Scanner v0.4.18 remains frozen.
