# v0.5.14 — Final Pre-Calibration Logic Lock

**Date:** 2026-09-15

v0.5.14 closes the final two logic questions before whole-system calibration.

## Training

- Locks the recovered normal-drill intensity ladder into runtime/tests: Very Easy/Easy/Medium/Hard/Very Hard = 1/2/3/4/5 base XP per player.
- Uses `base XP × drill-level effect` as the modeled drill gain strength.
- Ensures harder drills outrank easier drills in Max Growth when they hit the same useful target-gap whites at the same effect level. Intensity is a gain-strength factor, not a blanket hardest-drill rule: a lower-intensity drill can still win when it attacks substantially more important target gaps.
- Preserves Condition Efficient mode: condition rises proportionally with intensity, so no fake hard-drill efficiency multiplier is added.
- Continues to refuse invented exact normal-training percentage gains because final `AttributeGain` is server/runtime-owned.
- Removes stale unused repeat/coverage bonus fields from the decision contract.

## Captain

- Research conclusion: Captain has no proven match-performance effect.
- Captain is removed from every Team Plan score and tie-break.
- Team Plan persistence schema bumps to v5 so cached v0.5.13 plans are regenerated under the Captain-neutral contract.
- Automatic default becomes highest OVR starter, with role quality only as deterministic tie-breaks.
- Any starting-XI player can be manually selected without modeled performance penalty.
- No invented age, Bravery, Leadership/personality or hidden captain coefficient.

## Scope

Formation, Tactics, set-piece specialists, Mentors and Role+Playstyle target-shape development are otherwise unchanged from the v0.5.13 stitched architecture.
