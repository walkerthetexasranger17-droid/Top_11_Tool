# Top Eleven Tool v0.4.18

## Scanner v12 — native-resolution playstyle evidence

A real phone screenshot confirmed that Top Eleven captures the Skills screen at 2688×1216. Earlier scanner builds resized the entire screenshot to the canonical 1536×695 frame before locating the playstyle badge. That was appropriate for coordinate-locked OCR, but it unnecessarily destroyed detail in the tiny playstyle level ring.

Scanner v12 now uses a dual-path image pipeline:

- core OCR / skills / roles continue using the proven 1536×695 normalised frame;
- playstyle identity, level, context-matched references and the deterministic pixel comparator use the original source-resolution screenshot;
- playstyle ROI coordinates and badge-locator thresholds scale from the canonical geometry to the native screenshot dimensions;
- Ready/max-XP remains a separate overlay and is masked during underlying-level comparison;
- all approved HQ playstyle, compact scanner and coloured Special Ability assets remain unchanged.
