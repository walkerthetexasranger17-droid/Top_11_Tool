Scanner technical details

Scanner v12 keeps the original uploaded screenshot resolution for every field. The native 2688×1216 Top Eleven layout is the baseline; matching layouts at other resolutions use proportional ROI coordinates. Playstyle identity uses the verified compact-renderer reference pack, level confirmation uses the five exact badge references plus the local pixel comparator, and Special Abilities use only the 19 current coloured references. Results remain editable before saving.

API usage: requests use your Google AI Studio project directly, so quotas and billing follow that Google project.
